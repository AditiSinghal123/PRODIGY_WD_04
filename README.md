# Aditi Singhal — Personal Portfolio

A responsive portfolio website built with HTML, CSS, and vanilla JavaScript.

## Run in VS Code
1. Extract the ZIP.
2. Open the `aditi_portfolio` folder in VS Code.
3. Open `index.html` in a browser, or install/use the Live Server extension and select **Open with Live Server**.

## Customize before publishing
- Your profile photo is stored in `assets/aditi-profile.jpg`; replace it if you want to use a different professional photo.
- Update the LinkedIn profile URL in `index.html` with your actual profile URL.
- Your NPTEL Distributed Systems certificate is included in `assets/nptel-distributed-systems-certificate.pdf` and linked from the Education section.
- Review project summaries and repository links to make sure they match your actual projects.
- Add a real email address or contact form service if you want visitors to contact you directly.

## Files
- `index.html` — page structure and content
- `style.css` — design, layout, responsive behavior, and animations
- `script.js` — mobile menu, scroll reveal, active navigation, back-to-top, and rotating hero text
- `assets/aditi-profile.jpg` — profile photo
- `assets/nptel-distributed-systems-certificate.pdf` — NPTEL certificate

Note: Google Fonts requires an internet connection. No backend is required for this static portfolio.
